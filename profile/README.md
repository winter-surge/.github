## 关于我们

`winter-surge` 是一个专注于**红队攻防技术研究**与**安全工具开发**的组织。我们以《山海经》中的神兽为名，将传统安全攻防技艺与现代 AI 工程化方法结合，打造实战化的安全评估工具链。
